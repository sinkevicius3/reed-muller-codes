# Reed-Muller Codes

A Java console application for encoding and decoding first-order Reed-Muller codes `RM(1, m)`.

## Features

- Generate Reed-Muller codes
- Encode binary vectors
- Simulate transmission errors
- Allows manual modification of transmitted bits
- Decode and display the decoded message

## Run

Requires Java to run the existing executable JAR:

```bash
java -jar ReedMuller.jar
```
